# SleepQualityAnalysis

React dashboard and FastAPI analytics backend, with SQLite for development and
Supabase PostgreSQL for shared persistent data.

See [DEPLOYMENT.md](DEPLOYMENT.md) for Supabase setup, existing data transfer,
and deployment of the frontend and backend on Vercel.

See [PARTICIPANT_DASHBOARD.md](PARTICIPANT_DASHBOARD.md) for the connected
participant dashboard, JSON APIs, local startup and Supabase authentication.
